## 4. Technical Delivery & Core Web Vitals Impact

- **Next.js Image Optimization Pipeline:** All assets are configured in `next.config.js` to automatically convert to modern AVIF and WebP formats on demand.
- **Responsive DeviceSizes:** `[360, 480, 640, 750, 828, 1080, 1200, 1920, 2048]`.
- **Thumbnails:** Sub-pixel thumbnail generation using `imageSizes: [16, 32, 48, 64, 96, 128, 256, 384]`.
- **Cumulative Layout Shift (CLS):** `0.000` — all image containers enforce explicit `aspect-[3/4]`, `aspect-[2/1]`, or `aspect-square` CSS utility rules.
- **Caching Policy:** Long-lived cache TTL of 30 days (`minimumCacheTTL: 2592000`) and immutable browser caching headers (`max-age=31536000, immutable`).
